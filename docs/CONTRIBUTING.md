# Contributing

## Debian packaging

The debian source and binary packages are built in a container with [build.sh](../build.sh). The binary package is copied into [dist](../dist/).

### Manual pages

Manual pages in [install/man/](../install/man/) are in mardown and converted to roff (man page) format with `go-md2man`. These should be kept up-to-date as changes are made to the project. They are automatically generated by the debian build process.

```bash
# generate
./debian/rules man

# view it
man -l target/man/apt-transport-github.1
```
